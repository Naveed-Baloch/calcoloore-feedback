# CalcoloOre / OreChiare Feedback

Assistenza pubblica per [calcoloore.com](https://calcoloore.com/).

Usa [Segnala un problema o proponi una funzionalità](https://github.com/Naveed-Baloch/calcoloore-feedback/issues/new/choose).

Le segnalazioni e gli allegati sono pubblici. Usa esempi inventati; non pubblicare cartellini reali, nomi di dipendenti, email, documenti aziendali, password o altri dati riservati. Non è previsto un tempo di risposta garantito.

Il calcolatore è utilizzabile senza account; per inviare una segnalazione serve un account GitHub.

- [Guide](https://calcoloore.com/guide/)
- [Contatti e assistenza](https://calcoloore.com/contatti/)
- [Informativa sulla privacy](https://calcoloore.com/privacy/)

Questo repository contiene soltanto i moduli di feedback. Il codice del sito è gestito separatamente.
